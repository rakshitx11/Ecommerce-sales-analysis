# E-Commerce Sales Analysis Report

## 1. Introduction

This project analyzes an e-commerce sales dataset using Python, Pandas, and Matplotlib.

The main objective is to understand sales performance across different products, regions, and months and to identify meaningful patterns in the data.

The project follows a complete data analysis workflow:

**Data Loading → Data Cleaning → Data Exploration → Analysis → Visualization → Insights**

---

## 2. Project Objectives

The main objectives of this project are:

1. Load and understand the sales dataset.
2. Clean and validate the data.
3. Calculate important sales metrics.
4. Compare sales across different products.
5. Analyze regional sales performance.
6. Identify monthly sales trends.
7. Create meaningful visualizations.
8. Generate insights from the analysis.

---

## 3. Dataset Description

The dataset contains e-commerce transaction records.

| Column | Description |
|---|---|
| Date | Date of the transaction |
| Product | Product purchased |
| Quantity | Number of units purchased |
| Price | Price per unit |
| Customer_ID | Customer identifier |
| Region | Customer region |
| Total_Sales | Total value of the transaction |

---

## 4. Data Cleaning

The following data-cleaning operations were performed:

- Checked for missing values.
- Checked for duplicate records.
- Converted the Date column to datetime format.
- Converted numerical columns to numeric data types.
- Removed invalid or incomplete records.
- Validated Quantity, Price, and Total_Sales values.

## 7. Key Insights

The analysis produced the following key findings:

1. The total revenue generated was **₹12,365,048**.

2. **Laptop** was the best-performing product by revenue, generating **₹3,889,210**, which contributed approximately **31.5%** of total sales.

3. **Laptop** also had the highest quantity sold, with **136 units**.

4. **North** was the best-performing region, generating **₹3,983,635**, which contributed approximately **32.2%** of total sales.

5. **March 2024** was the highest-sales month, generating **₹4,485,006**.

6. **April 2024** was the lowest-sales month, generating **₹1,103,468**.

7. The dataset contains **100 unique customers**.

8. A total of **478 units** were sold across all transactions.

9. The average sales value per transaction was **₹123,650.48**.

### Product-wise Performance

| Product | Total Sales |
|---|---:|

### Region-wise Performance

| Region | Total Sales |
|---|---:|
| North | ₹3,983,635 |
| South | ₹3,737,852 |
| East | ₹2,519,639 |
| West | ₹2,123,922 |

These results show that laptops were the strongest product category, while the North region generated the highest revenue. Sales peaked in March 2024 and decreased significantly in April 2024.
