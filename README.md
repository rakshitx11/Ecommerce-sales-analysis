# E-Commerce Sales Data Analysis

## Project Overview

This project performs a complete data analysis of an e-commerce sales dataset using Python.

The project follows the complete data analysis pipeline:

**Load → Clean → Analyze → Visualize → Generate Insights**

The main objective is to understand sales performance across different products, regions, and months.

## Objectives

* Analyze overall sales performance.
* Identify the best-performing products.
* Compare sales across different regions.
* Analyze monthly sales trends.
* Identify useful patterns in the dataset.
* Present findings using professional visualizations.

## Technologies Used

* Python
* Pandas
* Matplotlib

## Dataset

The dataset contains 100 sales records with the following columns:

| Column      | Description                    |
| ----------- | ------------------------------ |
| Date        | Date of the transaction        |
| Product     | Product purchased              |
| Quantity    | Number of units purchased      |
| Price       | Price per unit                 |
| Customer_ID | Unique customer identifier     |
| Region      | Customer's region              |
| Total_Sales | Total value of the transaction |

## Setup Instructions

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project folder

```bash
cd ecommerce-sales-analysis
```

### 3. Install required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the analysis

```bash
python main.py
```

The program will automatically generate visualizations inside the `visualizations` folder.

## Data Processing

The project performs the following data-cleaning operations:

* Checks for missing values.
* Checks for duplicate records.
* Converts the Date column into datetime format.
* Validates numerical columns.
* Removes invalid or incomplete records.
* Validates quantity, price, and total sales values.

## Analysis Performed

The project calculates:

* Total sales revenue.
* Average transaction value.
* Total quantity sold.
* Number of unique customers.
* Sales by product.
* Quantity sold by product.
* Sales by region.
* Monthly sales.
* Highest-performing product.
* Highest-performing region.
* Highest and lowest sales months.

## Visualizations

### 1. Sales by Product

A bar chart is used to compare total revenue generated by different products.

### 2. Monthly Sales Trend

A line chart is used to identify changes in sales over time.

### 3. Sales by Region

A pie chart is used to show the contribution of each region to total sales.

## Key Insights

The program automatically generates insights based on the actual dataset.

Examples of insights include:

* Which product had the highest quantity sold.
* Which region generated the most revenue.
* Which month had the highest sales.
